# `data/processed/` — Processed & Model-Ready Data Layer

This directory is designated as the target repository for data transformations, preprocessed feature matrices, and pipeline artifacts generated by the **Phase 2 Data Preprocessing** workflows across both dataset tracks.

> **Current Storage Status**: This directory currently contains documentation only. In the current interactive notebook architecture, preprocessing transformations run in-memory within the respective Phase 2 notebooks (`notebooks/02_data_preprocessing.ipynb` and `notebooks/07_real_data_preprocessing.ipynb`). No serialized dataset files (`.csv`, `.parquet`, `.pkl`, `.joblib`) are permanently stored here.

---

## 1. What Belongs Here (When Serialized)

When pipeline serialization is enabled in future phases:
- **Cleaned & Encoded Feature Matrices**: `X_train_processed`, `X_test_processed`.
- **Target Label Arrays**: `y_train`, `y_test`.
- **Serialized Preprocessor Pipelines**: Saved `ColumnTransformer` pipelines (e.g., `preprocessor.joblib`).
- **Feature Name Mappings**: Machine-readable feature schema files.

## 2. Preprocessing Pipelines Overview

### Track 1: Synthetic Educational Dataset Preprocessing (`02_data_preprocessing.ipynb`)

```
                RAW DATASET (50 rows × 16 cols)
                              │
                              ▼
            STRATIFIED TRAIN / TEST SPLIT (80 / 20)
            ┌─────────────────┴─────────────────┐
            ▼                                   ▼
    X_train (40, 14), y_train (40,)     X_test (10, 14), y_test (10,)
            │                                   │
  Fit ColumnTransformer on X_train              │
            │                                   │
  Transform X_train                             │
            │                                   │
            └───────────────────────────► Transform X_test (using train params)
                                                │
                                                ▼
                                    X_test_processed (10, 16)
                                    [Uncontaminated Test Matrix]
```

- **Partitioning**: 80% Train (`40` rows: 25 non-default, 15 default) and 20% Test (`10` rows: 6 non-default, 4 default) using `stratify=y` and `random_state=42`.
- **Numerical Standardization**: `StandardScaler()` applied to 13 numerical columns, fitted strictly on `X_train`.
- **Categorical Encoding**: `OneHotEncoder(handle_unknown='ignore', sparse_output=False)` applied to `employment_type` (3 binary indicators).
- **Feature Dimensions**: 14 raw features $\rightarrow$ **16 model-ready features**.

### Track 2: Real-World UCI Benchmark Dataset Preprocessing (`07_real_data_preprocessing.ipynb`)

```
               RAW DATASET (1,000 rows × 21 cols)
                              │
                              ▼
            STRATIFIED TRAIN / TEST SPLIT (80 / 20)
            ┌─────────────────┴─────────────────┐
            ▼                                   ▼
   X_train (800, 20), y_train (800,)   X_test (200, 20), y_test (200,)
            │                                   │
  Fit ColumnTransformer on X_train              │
            │                                   │
  Transform X_train                             │
            │                                   │
            └───────────────────────────► Transform X_test (using train params)
                                                │
                                                ▼
                                    X_test_processed (200, N_features)
                                    [Uncontaminated Test Matrix]
```

- **Partitioning**: 80% Train (`800` rows: 560 non-default, 240 default) and 20% Test (`200` rows: 140 non-default, 60 default) using `stratify=y` and `random_state=42`.
- **Dynamic Feature Detection**: Numerical and categorical columns are detected dynamically at runtime from loaded DataFrame dtypes rather than assumed statically.
- **Dynamic Preprocessor**: `ColumnTransformer` with `StandardScaler()` for detected numerical columns and `OneHotEncoder(handle_unknown='ignore', sparse_output=False)` for detected categorical columns.
- **Feature Dimensions**: Dynamically computed via `preprocessor.get_feature_names_out()` and `X_train_processed.shape` (yielding 61 processed features for the 20 raw input features with standard encoding).

---

## 3. Data Leakage Prevention Protocol

To guarantee genuine out-of-sample generalization across both pipelines:
- The preprocessor object learns scaling statistics ($\mu, \sigma$) and categorical vocabulary **only from `X_train`**.
- `X_test` is transformed strictly using the training-fitted preprocessor.
- Target `default` and any database identifier columns are 100% quarantined from the feature matrix prior to fitting.

---

## 4. Reproducibility Guarantee

> **Reproducibility Principle**: All processed matrices can be fully regenerated deterministically at any time by executing `notebooks/02_data_preprocessing.ipynb` (synthetic pipeline) or `notebooks/07_real_data_preprocessing.ipynb` (UCI benchmark pipeline). Processed datasets are derived artifacts and should never be edited manually.
